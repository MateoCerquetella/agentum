The loop

Spawn. Watch. Hand off. Repeat.

Agentum runs your agents in a loop on a host you own. Each pass spawns work, watches the terminal, and hands the next task on — while the laptop sleeps in your bag.

01 — Sessions

It spawns agents on a host you own.

One Rust binary wires tmux to a control plane. Spawn Claude, Codex, Gemini — or any CLI on PATH — over SSH, with a live terminal stream and an input bar. Loopback by default; expose to your LAN when you choose.

02 — Watchdog & skills

It watches every terminal and recovers.

A per-session watchdog reads the pane: Context low auto-issues /compact, crash signatures emit session.crashed. Every run that ships keeps its method as a reusable skill.

03 — Board

It hands work between agents.

An atomic-claim kanban for cross-agent handoff. Drag columns, optimistic updates, a 409 on contention — so two agents never grab the same task. Channels broadcast 1:1 between sessions over a live event bus.

Install

Three commands and you're running.

Every step is a single cargo install-friendly binary. No daemon to chase, no compose file, no Docker.

01 — Install

One binary. Cargo or a native build.

Build from source with cargo, or grab the native desktop app for macOS. Pre-built targets for darwin-arm64, darwin-x86_64, linux-x86_64 and linux-aarch64.

02 — Spawn

Spin up an agent in any directory.

agentum new creates a tmux pane, attaches the right adapter (claude / codex / gemini / hermes / passthrough), and starts the watchdog.

03 — Serve

Open the dashboard from your phone.

HTTPS on :8822 with a self-signed cert; trust-on-first-use over plain HTTP :8823 so your phone can pin it once.

$cargo install --git https://github.com/mateocerquetella/agentum agentum
