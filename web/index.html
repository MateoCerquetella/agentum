Why I built this

I was running five AI agents on my Mac. Then I closed the lid to go to the supermarket and they all died. So I moved them to an old PC with Arch Linux, piped everything through tmux and WireGuard, and wrote shell scripts to spawn agents remotely. It worked — but now I was babysitting twenty tmux panes instead of writing code. agentum started as a weekend hack to get my life back. One Rust binary that turns tmux into a real control plane, plus a self-hosted dashboard I can check from my phone. No subscriptions, no cloud lock-in — just my agents, still running when I get home.

01Why agentum

Built for people
who run agents in parallel.

Problem You run 5–6 AI coding agents in parallel — Claude Code, Codex, Gemini, Hermes — and the minute you leave your desk, you lose all visibility.

Friction So you move them to a VPS, wrap them in tmux, and now you're babysitting tmux instead of code: switching panes, checking what crashed, manually compacting context before it overflows. Five sessions in, it's a second job.

agentum A single Rust binary that turns tmux into a proper control plane — every agent visible, every pane one click away, from any device.

  • Browser dashboard + TUI.Every agent live, side-by-side. Drop into any pane in one click.
  • Embedded lazygit panel.See diffs, stage hunks, commit — without leaving the session.
  • Watchdog.Auto-detects crashes. Auto-compacts context before it overflows.
  • PWA on your phone.Close the lid. Keep watching every agent from anywhere.

01 — Sessions

Spawn agents in tmux. Stream them anywhere.

Each session is a tmux pane managed by Rust + tokio. Bidirectional WebSocket stream means xterm.js in the browser and ratatui in the TUI both round-trip keystrokes — Ctrl-C, arrow keys, paste — into the running pty.

04 — Channels

1:1 message pipes between sessions.

One agent finishes a migration, posts the resulting schema diff into a channel. Another agent — already running tests — reads it live over the shared event bus and adapts.

The same SQLite-backed event bus powers every surface. Your tmux panes don't care which window you're in.

02From shell to dashboard

Three commands
and you're running.

Every step is a single cargo install-friendly binary. No daemon to chase, no compose file, no Docker.

01 Install

One binary. Cargo or curl.

Pre-built tarballs for darwin-arm64, darwin-x86_64, linux-x86_64, and linux-aarch64 — verified against SHA256SUMS.

02 Spawn

Spin up an agent in any directory.

agentum new creates a tmux pane, attaches the right adapter (claude / codex / gemini / hermes / passthrough), and starts the watchdog.

03 Serve

Open the dashboard from a phone.

HTTPS on :8822 with a self-signed cert; trust-on-first-use over plain HTTP :8823 so your phone can pin it once.
