The loop

Spawn. Watch. Hand off. Repeat.

Agentum runs your agents in a loop on a host you own. Each pass spawns work, watches the terminal, and hands the next task on — while the laptop sleeps in your bag.

01 — Sessions

It spawns agents on a host you own.

One Rust binary wires tmux to a control plane. Spawn Claude, Codex, Gemini — or any CLI on PATH — over SSH, with a live terminal stream and an input bar. Loopback by default; expose to your LAN when you choose.

02 — Watchdog & skills

It watches every terminal and recovers.

A per-session watchdog reads the pane: Context low auto-issues /compact, crash signatures emit session.crashed. Every run that ships keeps its method as a reusable skill.

03 — Board

It hands work between agents.

Pull issues and PRs from GitHub and Linear onto an atomic-claim board, then hand them to agents. Optimistic drag, a 409 on contention — so two agents never grab the same task.

Install

Three commands and you're running.

One static binary — cargo install or curl | sh. No daemon to chase, no compose file, no Docker.

01

Install

One static binary on your PATH. macOS & Linux, arm64 & x86_64.

02

Spawn

Point an agent at any repo — it lands in its own tmux pane with a watchdog.

03

Serve

One daemon. Drive it from the desktop app, the TUI, or your phone.

zsh — ~/Developer/agentum 
# 1 · install — one static binary  (or: cargo install --git …/agentum agentum-cli)
$ curl -fsSL https://github.com/mateocerquetella/agentum/releases/latest/download/install.sh | sh
  ✓ agentum 0.13.3 → ~/.local/bin/agentum

# 2 · spawn an agent in any repo
$ agentum new alpha --tool claude --dir ~/Developer/agentum --up
  ✓ session alpha · tmux pane agentum:alpha.0
  ✓ adapter claude · opus-4.8 · watchdog armed (5s tick)

# 3 · start the daemon — desktop app, TUI & phone all attach here
$ agentum serve
  auth disabled — loopback bind, only this machine can reach the daemon
