# Security boundary

Agentum's trusted main desktop webview communicates with the embedded Agentum server only over a stable loopback HTTP/WebSocket endpoint and with Tauri over its IPC scheme. Each desktop boot mints a high-entropy UI bearer in memory. The Tauri endpoint command that returns it is registered in the application ACL and granted only to the `main` webview; browser-page child webviews cannot invoke it. The bearer is not persisted, logged, mounted into a provider sandbox, or injected into an agent process. External provider, tracker, Git, SSH, and model traffic is performed by the native backend. The renderer Content Security Policy therefore keeps `connect-src` limited to Tauri IPC and `127.0.0.1`; adding an arbitrary HTTP, HTTPS, WebSocket, or secure-WebSocket destination requires a security review.

The UI bearer and MCP bearer are separate credentials. MCP rotation and persistence cannot authorize desktop HTTP actions, and the UI bearer is never present in generated MCP configuration. Provider sandboxes retain the network egress needed for model transports, so loopback origin is never treated as identity. Even when a standalone daemon is launched with `--no-auth`, every `/api/sdd` HTTP and WebSocket route—including reads, events, source import, run creation, approvals, and delivery—requires either a database-backed human session or the embedded main-webview capability. SDD command handlers enforce the human mutation boundary again as defense in depth.

`img-src https:` is intentionally broader. Agentum displays user-selected Markdown images, browser favicons, release media, and avatars returned by GitHub, GitLab (including self-hosted installations), Linear, Jira, and other configured work-item providers. Those hosts are dynamic and cannot be represented by a static origin list. Plaintext remote images, scripts, objects, forms, and frames remain blocked. Local files are read through an authorized native operation and rendered as blob URLs instead of exposing `file:` access to the renderer.

The macOS App Transport Security exception permits local networking only. The bundle configuration retains the hardened runtime and the microphone-only audio-input entitlement for native voice dictation. Releases do not require Apple credentials, so macOS bundles are not signed with an Apple Developer ID certificate or notarized; Gatekeeper may require the user to control-click the app and choose Open on first launch. The release workflow still validates the bundle structure, identifier, microphone usage declaration, local-networking-only ATS policy, disk image, and Tauri updater signature before publication.

Windows release executables are not Authenticode-signed, so Microsoft Defender SmartScreen may warn on first launch. They still carry a Tauri updater signature, and the workflow rejects any updater artifact that does not verify against the public key embedded in the application.

Release dependency policy is enforced by `scripts/check-rust-dependencies.sh` and `bun audit`. Third-party workflow actions are pinned to immutable commits and are updated through Dependabot. Repository and generated artifacts are scanned using an externally supplied restricted-content pattern set; the release fails when that pattern set is unavailable. Publication accepts only a verified, signed, annotated version tag whose commit is exactly the current `main` tip. Repository rules and branch protection are deployment controls outside this checkout and must be audited separately before publication. Before a draft is created, every updater bundle is verified cryptographically against the public key embedded in the desktop application, including explicit tamper and wrong-key tests in the core verifier.

GitHub vulnerability alerts, Dependabot security updates, and immutable releases are enabled for the repository. Publication creates a private draft only after every artifact and updater signature is validated, synchronizes the Homebrew cask with a tap-scoped deploy key and GitHub's pinned published SSH host key, and then publishes once. GitHub prevents mutation of the published release and its assets.
