agentum — brand mark (Swarm / Blocks)
=====================================

A fleet of cursor-blocks resolving into one upward chevron, sized by depth.
Monochrome — black and white only.

Files (all vector SVG, viewBox 0 0 100 100 unless noted):
  mark-on-dark.svg     White-to-grey mark, transparent bg. Use on dark surfaces.
  mark-on-light.svg    Dark-to-grey mark, transparent bg. Use on light surfaces.
  app-icon-tile.svg    White mark on the brand near-black rounded tile (app icon).
  favicon.svg          Tile version sized for a browser tab.
  lockup-on-dark.svg   Mark + "agentum" wordmark, white (320x100).
  lockup-on-light.svg  Mark + "agentum" wordmark, dark (320x100).

Notes:
  - Wordmark is set in IBM Plex Sans Medium, -0.04em tracking. The SVG references
    the font by name; install/embed IBM Plex Sans for an exact match, or convert
    the text to outlines in your design tool.
  - Clear space: keep at least the height of the apex block clear on all sides.
  - Don't recolour, rotate, or restyle the blocks; don't add the old coral lead.
