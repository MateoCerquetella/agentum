Date: 2026-08-01

## Baseline

- GitHub release API: `immutable: true`
- Repository immutable releases: `enabled: true`
- Public `latest.json` SHA-256 before/after attempt:
  `221159eaee2b6a5193382c6e1e05e79887dde248d9554484ebc40cc1c18c5f5a`
- Public platform keys:
  `darwin-aarch64,darwin-x86_64,linux-x86_64,windows-x86_64`
- Candidate platform keys: `linux-x86_64,windows-x86_64`

## Authorized replacement attempt

The exact v0.98.11 `latest.json` was downloaded, transformed by deleting only
`darwin-aarch64` and `darwin-x86_64`, and submitted once with GitHub CLI's
supported release-asset `--clobber` operation.

Result:

```text
HTTP 422: Validation Failed
Cannot delete asset from an immutable release
```

The live asset was re-downloaded after the attempt. Its SHA-256 and four-key
platform set were unchanged. No immutable setting, release tag, historical
asset, or repository protection was bypassed. Containment therefore requires a
newer release whose `/releases/latest/download/latest.json` contains only the
two supported platforms.
