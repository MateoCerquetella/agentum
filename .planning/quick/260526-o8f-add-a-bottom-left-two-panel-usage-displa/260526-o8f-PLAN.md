**Helpers (all `pub(super) fn`, all pure, no I/O):**

1. `format_tokens(t: Option<i64>) -> String`
   - `None` → `"—"` (em-dash U+2014)
   - `Some(n)` where `n < 0` → `"—"` (treat negative as missing)
   - `Some(n)` where `n < 1_000` → decimal string (e.g. `"999"`)
   - `Some(n)` where `n < 1_000_000` → `"{X.Yk}"` using one decimal, e.g. 1500 → `"1.5k"`, 42_000 → `"42.0k"`. Format with `format!("{:.1}k", n as f64 / 1000.0)`.
   - `Some(n)` where `n >= 1_000_000` → `"{X.YM}"`, e.g. 1_500_000 → `"1.5M"`. Format with `format!("{:.1}M", n as f64 / 1_000_000.0)`.

2. `format_cost(c: Option<f64>) -> String`
   - `None` → `"—"`
   - `Some(v)` where `!v.is_finite() || v < 0.0` → `"—"`
   - else → `format!("${:.2}", v)` (e.g. 0.314 → `"$0.31"`).

3. `format_ctx(p: Option<i32>) -> String`
   - `None` → `"—"`
   - `Some(v)` where `v < 0 || v > 100` → `"—"` (out-of-range guard)
   - else → `format!("{}%", v)`.

NOTE: The task brief specified `Option<u64>` / `Option<u8>`. The real `Session` struct uses `Option<i64>` / `Option<i32>` (see context interfaces). Use the real types.

**Render function:**

`pub(super) fn draw_usage_panel(f: &mut Frame<'_>, area: Rect, app: &App, p: &Palette)`

Behavior:
- If `area.width == 0 || area.height == 0` → return (no-op, matches existing pattern).
