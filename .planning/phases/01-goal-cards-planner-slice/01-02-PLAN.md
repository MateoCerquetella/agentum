Define a private deserialise-shape that mirrors `planner.toml`:
```rust
#[derive(serde::Deserialize, Default)]
struct PlannerFile {
    planner: Option<PlannerSection>,
}
#[derive(serde::Deserialize, Default)]
struct PlannerSection {
    tool: Option<String>,
    prompt_file: Option<String>,
    prompt: Option<String>,
}
```

Public function:
```rust
pub async fn load_planner_config() -> Result<PlannerConfig, crate::error::ApiError> {
    let path = agentum_store::paths::planner_config_path()
        .map_err(|e| crate::error::ApiError::Internal(format!("planner config path: {e}")))?;

    if !path.exists() {
        return Ok(PlannerConfig {
            tool: DEFAULT_TOOL.into(),
            prompt: Cow::Borrowed(BUNDLED_PROMPT),
        });
    }

    let raw = tokio::fs::read_to_string(&path).await
        .map_err(|e| crate::error::ApiError::Internal(format!("read planner.toml: {e}")))?;

    let parsed: PlannerFile = toml::from_str(&raw)
        .map_err(|e| crate::error::ApiError::BadRequest(format!("invalid planner.toml: {e}")))?;

    let section = parsed.planner.unwrap_or_default();
    let tool = section.tool.unwrap_or_else(|| DEFAULT_TOOL.to_string());

    // Resolution order: prompt_file -> prompt -> bundled
    let prompt: Cow<'static, str> = if let Some(pf) = section.prompt_file.as_ref() {
        let abs = Path::new(pf);
        // Path-traversal guard (security_threat_model T-02-01): must be absolute,
        // no `..` segments. The user owns the file, but we refuse relative paths
        // so an attacker who can write planner.toml can't pivot through a
        // working-directory-relative ../etc/secret.
        if !abs.is_absolute() {
            return Err(crate::error::ApiError::BadRequest(
                format!("planner.prompt_file must be an absolute path: {pf}")
            ));
        }
        if abs.components().any(|c| matches!(c, std::path::Component::ParentDir)) {
            return Err(crate::error::ApiError::BadRequest(
                format!("planner.prompt_file must not contain `..`: {pf}")
            ));
        }
        if !abs.exists() {
            return Err(crate::error::ApiError::BadRequest(
                format!("planner.prompt_file does not exist: {pf}")
            ));
        }
        let body = tokio::fs::read_to_string(abs).await
            .map_err(|e| crate::error::ApiError::Internal(format!("read prompt_file: {e}")))?;
        Cow::Owned(body)
    } else if let Some(inline) = section.prompt {
        Cow::Owned(inline)
    } else {
        Cow::Borrowed(BUNDLED_PROMPT)
    };

    Ok(PlannerConfig { tool, prompt })
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk→daemon | The daemon reads `planner.toml` and the referenced `prompt_file` from disk. The user owns these files in principle, but a misconfigured `prompt_file` could expose system files if the daemon blindly resolves the path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | load_planner_config / prompt_file resolution | mitigate | Reject relative paths AND any path containing `..` segments. Test cases `prompt_file_relative_is_rejected` + `prompt_file_parent_dir_is_rejected` enforce this. The threat is: an attacker who can write `planner.toml` can pivot to read `/etc/passwd` if we resolve relative paths against the daemon's CWD. (The user already trusts the daemon to read their config, so absolute-only is the right line.) |
| T-02-02 | Tampering | load_planner_config / TOML parse | mitigate | `toml::from_str` returns a typed error; we map to `ApiError::BadRequest("invalid planner.toml: ...")`. Bad input cannot panic the handler. |
| T-02-03 | Denial of Service | load_planner_config called per goal-submit | accept | Per D-12 (no in-memory cache in v1). The file is small (~1KB max), reads are tokio::fs::read_to_string (async). At realistic goal-submit rates (<<1 Hz) this is fine. Phase 3 may add caching if profiling shows hot-path cost. |
| T-02-04 | Information Disclosure | BUNDLED_PROMPT content | accept | The bundled prompt is public — it teaches the agent how to call our public CLI. Not sensitive. |
| T-02-05 | Tampering | planner_config_path()'s implicit XDG_CONFIG_HOME respect | accept | `paths::config_dir()` already honours `XDG_CONFIG_HOME` via the `directories` crate. Tests force this via `set_var`. Production behaviour matches `auth_token_path` / `tls_dir` precedent. |
</threat_model>
