<objective>
Add the goal-status auto-progression subscriber: a tokio task subscribed to the broadcast bus that listens for `board.created` / `board.updated` / `board.deleted` events whose payload references a row with `parent_goal_id IS NOT NULL`, recomputes `max(child statuses)` for that parent, and patches the goal card if the rank differs. Also handles the planner auto-stop (D-07): when the first child arrives for a goal, emit `goal.planner.first_child` and stop the planner session bound via `session.card_id = goal.id`.

Purpose: this enforces D-03's "goal.status = max(child statuses)" invariant and D-07's "auto-stop on first child" rule. The watchdog is the only writer of auto-goal-status; no client PATCH ever computes this.

Output: new module function in `crates/agentum-watchdog/src/lib.rs` that spawns alongside the existing reconciler, plus inline tests that drive synthetic events through the bus and assert the goal-status patch + planner-stop side effects.
</objective>

```rust
/// Subscribes to the broadcast bus and reconciles goal statuses
/// against their children per CONTEXT D-03.
/// Spawned alongside `Watchdog::run` in `agentum-server::serve()`.
pub async fn run_goal_reconciler(
    store: Arc<Store>,
    bus: tokio::sync::broadcast::Sender<Event>,
) {
    let mut rx = bus.subscribe();
    let mut planner_stopped: std::collections::HashSet<i64> = std::collections::HashSet::new();

    loop {
        let ev = match rx.recv().await {
            Ok(ev) => ev,
            Err(tokio::sync::broadcast::error::RecvError::Closed) => break,
            Err(tokio::sync::broadcast::error::RecvError::Lagged(n)) => {
                tracing::warn!(lagged = n, "goal reconciler lagged");
                continue;
            }
        };
        if !matches!(ev.kind.as_str(), "board.created" | "board.updated" | "board.deleted") {
            continue;
        }
        if let Err(e) = handle_board_event(&store, &bus, &ev, &mut planner_stopped).await {
            tracing::warn!(error = ?e, kind = %ev.kind, "goal reconcile failed");
        }
    }
}
```

Then the helpers:

```rust
async fn handle_board_event(
    store: &Store,
    bus: &tokio::sync::broadcast::Sender<Event>,
    ev: &Event,
    planner_stopped: &mut std::collections::HashSet<i64>,
) -> Result<(), WatchdogError> {
    let Some(goal_id) = extract_parent_goal_id(store, ev).await? else {
        return Ok(());
    };

    let goal = match store.get_board_item(goal_id).await {
        Ok(item) => item,
        Err(_) => return Ok(()),  // Goal gone; nothing to reconcile.
    };

    // Depth-1 invariant per CONTEXT D-03 + PATTERNS.md.
    if goal.parent_goal_id.is_some() {
        tracing::warn!(goal_id, "v1 invariant violated: goal has a parent; skipping recompute");
        return Ok(());
    }

    // D-07 planner auto-stop, ONLY on first board.created child observed.
    if ev.kind == "board.created" && planner_stopped.insert(goal_id) {
        if let Some(session) = store.get_session_by_card_id(goal_id).await? {
            if matches!(session.status, agentum_core::Status::Running) {
                // Emit the event BEFORE the tmux call so tests without a real
                // tmux fixture can still observe the event. The tmux call is
                // best-effort; failure logs a warning but the event already
                // fired and downstream observers (dashboard, TUI) see "first
                // child arrived" regardless.
                let _ = bus.send(
                    Event::new("goal.planner.first_child")
                        .with_payload(serde_json::json!({
                            "goal_id": goal_id,
                            "planner_session_id": session.id.to_string(),
                        })),
                );
                let target = agentum_tmux::target_for(&session.name);
                if let Err(e) = agentum_tmux::graceful_stop(&target).await {
                    tracing::warn!(error = %e, session = %session.name, "planner graceful_stop failed");
                }
            }
        }
    }

    // Recompute goal status (D-03 invariant). The `max_child_status_rank`
    // SQL returns `-1` when a child has an unknown status string (defensive
    // CASE arm) and NULL when there are no children. Handle each case
    // explicitly — never silently coerce -1 to 0.
    let rank = store.max_child_status_rank(goal_id).await?;
    let target_status = match rank {
        // No children: D-03 says goal stays at todo (max of empty set).
        None => "todo",
        // All children have known statuses.
        Some(0) => "todo",
        Some(1) => "doing",
        Some(2) => "done",
        // Negative => at least one child has an unrecognized status string
        // (legacy data or future-status). Log + skip; do NOT silently
        // demote the goal.
        Some(r) if r < 0 => {
            tracing::warn!(goal_id, rank = r, "child has unknown status; skipping recompute");
            return Ok(());
        }
        Some(other) => {
            tracing::warn!(goal_id, rank = other, "unexpected child status rank; skipping recompute");
            return Ok(());
        }
    };
    let target_rank = status_rank(target_status);
    let current_rank = status_rank(&goal.status);
    if current_rank == target_rank {
        return Ok(());
    }

    let patch = agentum_core::BoardPatch {
        status: Some(target_status.to_string()),
        ..Default::default()
    };
    let _ = store.patch_board_item(goal_id, patch).await?;
    let _ = bus.send(
        Event::new("goal.status.changed")
            .with_payload(serde_json::json!({
                "goal_id": goal_id,
                "from": goal.status,
                "to": target_status,
            })),
    );
    Ok(())
}

async fn extract_parent_goal_id(store: &Store, ev: &Event) -> Result<Option<i64>, WatchdogError> {
    if let Some(pg) = ev.payload.get("parent_goal_id").and_then(|v| v.as_i64()) {
        return Ok(Some(pg));
    }
    if ev.payload.get("parent_goal_id").is_some_and(|v| v.is_null()) {
        return Ok(None);
    }
    // Fall back to DB lookup for board.updated only (board.deleted: row is gone).
    if ev.kind == "board.deleted" {
        return Ok(None);
    }
    if let Some(id) = ev.payload.get("id").and_then(|v| v.as_i64()) {
        if let Ok(item) = store.get_board_item(id).await {
            return Ok(item.parent_goal_id);
        }
    }
    Ok(None)
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| bus→watchdog | The reconciler trusts events from the bus. Bus producers are already authenticated (routes behind require_token; the goal-create handler emits the events). |
| watchdog→Store | Direct writes via Store::patch_board_item bypass enforce_transition. This is deliberate (D-03 invariant) and scoped to status changes only. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | run_goal_reconciler patches goal status without enforce_transition | mitigate | The bypass is intentional per PATTERNS.md ("the watchdog bypasses the gate by writing through Store::patch_board_item directly"). Scoped to setting `status` only; never touches other fields. Goals never enter `doing` without a real child driving them there, so the bypass cannot be triggered from an external client without first creating + patching a child via the auth-gated routes. |
| T-04-02 | Denial of Service | Reconciler lag under bus pressure | mitigate | `RecvError::Lagged(n)` logs a warning and continues. The next event triggers a fresh recompute via `max_child_status_rank`, which re-reads from the DB — convergent recovery. No persistent inconsistency possible because the recompute always reads ground truth. |
| T-04-03 | Elevation of Privilege | A malicious child PATCH triggers an arbitrary goal status | accept | The recomputer's output is bounded by `max_child_status_rank` (the SQL CASE expression). Worst case: an attacker who can PATCH a child can drive its parent goal to `doing` or `done`. The attacker already had auth (require_token), so this is equivalent to the existing PATCH capability — no new escalation. |
| T-04-04 | Information Disclosure | goal.status.changed event payload | accept | Contains goal_id + status strings. No PII. Bus subscribers are already authenticated. |
| T-04-05 | Tampering | planner_stopped HashSet persistence (in-memory only) | accept | If the daemon restarts mid-planner-run, the HashSet resets and the next child-arrival event will fire `goal.planner.first_child` again. The planner pane may already have been killed by the previous run, so the duplicate `graceful_stop` call would error-log; harmless. v2 may persist this set to DB if it matters. |
</threat_model>
