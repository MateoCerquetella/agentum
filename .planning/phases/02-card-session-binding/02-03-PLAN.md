<objective>
Wire the PATCH `/api/board/{id}` handler to honor three new branches:

1. **Auto-spawn** when `target_status == "doing"` AND the merged `session_id` is `None` (BIND-01).
2. **Unbind** when the request body has `session_id: null` (BIND-06).
3. **Rebind** when the request body has `session_id: "<uuid>"` (BIND-06).

All three branches preserve the existing gate-first invariant (`enforce_transition` runs first). The auto-spawn delegates to a new `spawn_card_session` helper in `board_goals.rs` — the same shape as Phase 1's `spawn_planner_session` but parameterised on the card directly. The helper calls `Store::claim_card` (plan 02-01) inside the route, and the unbind/rebind branches call `Store::transfer_card_binding` (plan 02-01).

Purpose: This is the keystone slice — the user-observable behavior CONTEXT D-01 specifies. After this plan lands, a developer can `curl -X PATCH .../board/{id} -d '{"status":"doing"}'` and see a session spawn and bind atomically.

Output: PATCH handler updated, new helper `spawn_card_session` exposed, full unit-test coverage of all three new branches plus the missing-workdir 400 path and the rebind-to-already-bound 409 path.
</objective>

           card: &BoardItem,

           // 1. Resolve tool: card.tool → parent_goal.tool → "claude"
           let tool = match card.tool.as_deref() {
               Some(t) => t.to_string(),

        // unbind/rebind branch (explicit field present in body)
        let new_sid = match &patch.session_id {
            Some(Some(s)) => Some(Uuid::parse_str(s).map_err(|e| ApiError::BadRequest(e.to_string()))?),

            None => unreachable!(),  // outer if guarded

        // OR call transfer_card_binding first and then a slimmer patch.
        // Choose: call transfer_card_binding FIRST (it sets session_id atomically),
        // then call patch_board_item with a *clone* of patch that has session_id
        // set to None so the store doesn't try to re-set the same column.
        state.store.transfer_card_binding(id, new_sid).await?;

        patch = patch_without_session;
    }
