<objective>
Land the watchdog→comment bridge: a new bus-subscriber task that converts the three observable agent events (`agent.awaiting_input`, `agent.finished`, `session.crashed`) into `[system]` comments on the bound card's thread.

Purpose: This is the **observability slice** for Phase 2. Without it, the user sees the card's status flip and the session pane open, but nothing connects watchdog events back to the card's thread. After this plan, every card with a bound session accumulates a chronological audit trail of what its agent did.

The bridge is a sibling task to Phase 1's `run_goal_reconciler` — same shape, same idempotency pattern, same bus-lag policy.

Output: One new public `pub async fn run_session_comment_bridge` in `agentum-watchdog`, one new `tokio::spawn` site in `agentum-server::serve`, full unit-test coverage of all three event kinds + the goal-card filter + the dedupe + the bus-lag handling.
</objective>

```rust
pub async fn run_goal_reconciler(store: Arc<Store>, bus: tokio::sync::broadcast::Sender<Event>) {
    let mut rx = bus.subscribe();
    let mut planner_stopped: HashSet<i64> = HashSet::new();
    loop {
        let ev = match rx.recv().await {
            Ok(ev) => ev,
            Err(RecvError::Closed) => break,
            Err(RecvError::Lagged(n)) => {
                tracing::warn!(lagged = n, "goal reconciler lagged; will recompute on next event");
                continue;
            }
        };
        if !matches!(ev.kind.as_str(), "board.created" | "board.updated" | "board.deleted") {
            continue;
        }
        if let Err(e) = handle_board_event(&store, &bus, &ev, &mut planner_stopped).await {
            tracing::warn!(error = ?e, kind = %ev.kind, "goal reconcile failed");
        }
    }
}
```

    ```rust
    /// Bridge from watchdog/agent events onto the bound card's comment thread.
    ///
    /// CONTEXT D-05: separate bus-subscriber task (not folded into watch_session),
    ///   sibling to run_goal_reconciler.
    /// CONTEXT D-06: body templates + 80-char signature cap.
    /// CONTEXT D-07: in-memory HashMap<session_id, &'static str> dedupe;
    ///   skip identical back-to-back inserts.
    /// CONTEXT D-08: skip events on goal cards (lbl == "goal") — the goal
    ///   reconciler already surfaces those state changes via goal.status.changed.
    /// CONTEXT D-09: RecvError::Lagged logs warn and continues; no resync.
    pub async fn run_session_comment_bridge(
        store: Arc<Store>,
        bus: tokio::sync::broadcast::Sender<Event>,
    ) {
        use tokio::sync::broadcast::error::RecvError;
        let mut rx = bus.subscribe();
        // Last comment kind per session; dedupes back-to-back identical inserts.
        let mut last_kind: std::collections::HashMap<Uuid, &'static str> =
            std::collections::HashMap::new();

        loop {
            let ev = match rx.recv().await {
                Ok(ev) => ev,
                Err(RecvError::Closed) => break,
                Err(RecvError::Lagged(n)) => {
                    tracing::warn!(
                        lagged = n,
                        "session_comment_bridge: bus lagged; will resume on next event"
                    );
                    continue;
                }
            };
            // Filter to the three observable agent events ONLY.
            let kind: &'static str = match ev.kind.as_str() {
                "agent.awaiting_input" => "awaiting_input",
                "agent.finished" => "finished",
                "session.crashed" => "crashed",
                _ => continue,
            };
            if let Err(e) = handle_session_event(&store, &ev, kind, &mut last_kind).await {
                tracing::warn!(
                    error = ?e, kind = %ev.kind,
                    "session_comment_bridge: handle failed"
                );
            }
        }
    }

    async fn handle_session_event(
        store: &Store,
        ev: &Event,
        kind: &'static str,
        last_kind: &mut std::collections::HashMap<Uuid, &'static str>,
    ) -> Result<(), WatchdogError> {
        let Some(session_id) = ev.session_id else { return Ok(()); };

        // Resolve the bound card (if any).
        let session = match store.get_session(session_id).await? {
            Some(s) => s,
            None => return Ok(()),  // concurrent session delete; benign
        };
        let Some(card_id) = session.card_id else { return Ok(()); };

        // Goal-card filter (CONTEXT D-08).
        let card = match store.get_board_item(card_id).await? {
            Some(c) => c,
            None => return Ok(()),  // card was deleted; benign
        };
        if card.lbl.as_deref() == Some("goal") {
            return Ok(());
        }

        // In-memory dedupe.
        if last_kind.get(&session_id) == Some(&kind) {
            return Ok(());
        }
        last_kind.insert(session_id, kind);

        // Compose the body template (CONTEXT D-06 + UI-SPEC §Copywriting Contract).
        let body = match kind {
            "awaiting_input" => "[system] agent awaiting input".to_string(),
            "finished"       => "[system] agent finished".to_string(),
            "crashed" => {
                let raw_sig = ev.payload.get("signature")
                    .and_then(|v| v.as_str())
                    .map(|s| s.trim())
                    .filter(|s| !s.is_empty())
                    .unwrap_or("unknown");
                let sig: String = raw_sig.chars().take(80).collect();
                format!("[system] session crashed: {sig}")
            }
            _ => unreachable!("kind is one of the three matched literals above"),
        };

        store.create_board_comment(
            card_id,
            agentum_core::NewBoardComment {
                author: "system".to_string(),
                body,
            },
        ).await?;

        Ok(())
    }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| bus→bridge | Tokio broadcast channel. Source: trusted in-daemon emitters (watchdog activity classifier, route handlers). No untrusted input crosses this boundary. |
| bridge→Store | In-process call to `Store::create_board_comment`. Bypasses HTTP. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-15 | Tampering | Malicious event payload injects huge `signature` string | mitigate | The 80-char chars-take cap (Test 5) prevents comment-body amplification. The body uses `format!` with a sanitised substring — no raw bytes pass through. |
| T-02-16 | Denial of service | Storm of agent.* events floods comment table | accept | The dedupe (Test 8) collapses identical back-to-back inserts. Across distinct events, the volume is bounded by actual agent activity (which is human-scale, not machine-scale). |
| T-02-17 | Repudiation | Bridge crashes mid-flight, missing a comment | mitigate | Per CONTEXT D-09, a missed `[system]` comment is benign — the card's state of record is `session.status` + `card.status`, both of which the goal reconciler keeps converged. The bridge is informational, not authoritative. |
| T-02-18 | Information disclosure | Comment body leaks sensitive pane content via signature | accept | The signature comes from the watchdog's crash-signature regex matches, which target known patterns like `panicked`, `SIGSEGV`, `Error:` — none of which carry secrets. Pane content is NOT included in the comment body. |
| T-02-19 | Spoofing | A non-agent emitter sends `agent.finished` events to write `[system]` rows | accept | Bus emitters are trusted in-daemon code paths only; no external producer reaches the bus. |
| T-02-SC | Tampering | No new package installs | n/a | Code-only changes; no `Cargo.toml` additions; `tempfile` already in dev-deps from Phase 1. |
</threat_model>
